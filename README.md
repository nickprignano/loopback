# Loopback

An original snake-style browser game with a twist: sparks dodge your head, so the only way to
catch them is to loop your body all the way around them. Plain JavaScript and canvas, no build
step. MIT licensed.

The plan is in [docs/SPEC.md](docs/SPEC.md). Nothing is built yet.

The idea of catching things by circling them with your body comes from
[Blasnake](https://abagames.itch.io/blasnake) by abagames (MIT); the code here will be our own.
The site look is [prignano-theme](https://github.com/nickprignano/prignano-theme) (MIT).
